## 想清楚为什么要放到服务器上

放在一台一直开着的机器上，有两个好处：

- **合上笔记本，它还在干活。** [第 6 步](/guide/6-automations/)的自动化到点就能跑。
- **外面的服务更容易叫醒它。** 比如 Slack、GitHub 的事件。

机器可以是云服务器，也可以是一台 Mac Mini 这样的闲置电脑。一个人用，Ubuntu 24.04 LTS、2 核 CPU、4 GB 内存就够了。

<Callout type="no" title="把这台机器当成放着生产密钥的机器">
代理能读写这台机器上的文件、运行命令、访问网络。谁能连上 Agent Server，谁就能做同样的事。<mark><strong>先锁好门，再启动服务。</strong></mark>
</Callout>

## 先装防火墙，再启动

在第一次启动之前，到云服务商的防火墙里设好：

- **SSH（22 端口）**：只允许你自己的 IP 或 VPN 网段。
- **其他所有端口**：一律拒绝。`8000`、`18000`、`18001`、`3001` 都不能从外面访问。

这样设好后，只有 SSH 能进来。用 SSH 隧道就足够跑起来、打开界面了。

## 在服务器上启动

装好 Node.js 24 和 `uv`。Ubuntu 上：

<Copy id="prereq" lang="bash" title="装依赖（Ubuntu）" code={`apt-get update
apt-get install -y curl git
# Node.js 24.x (use nvm, asdf, or NodeSource — whatever you prefer)
# uv (for the agent-server uvx runtime):
curl -LsSf https://astral.sh/uv/install.sh | sh`} />

macOS 上用 `brew` 装 Node 和 `uv`。

然后用 public 模式启动：

<Copy id="public" lang="bash" title="生成密钥并启动" code={`export LOCAL_BACKEND_API_KEY=$(openssl rand -base64 32)   # generate once; store securely
npx @openhands/agent-canvas --public`} />

第一行生成一个随机密钥。<u>把它打印出来，存到安全的地方</u>，之后每次连接都要用。

`--public` 让页面不再自动带上密钥，谁打开界面都要先输入它。不加 `--public`，密钥会直接放进页面里，只适合在自己电脑上用。

SSH 断开后还想让它跑，用 tmux：

<Copy id="tmux" lang="bash" title="放进 tmux 里一直跑" code={`export LOCAL_BACKEND_API_KEY=<your-saved-key>
tmux new-session -d -s canvas 'npx @openhands/agent-canvas --public'
# Reconnect later with: tmux attach -t canvas`} />

把 `<your-saved-key>` 换成你存下的密钥。长期跑的话，官方推荐用 systemd，见下面的官方指南。

## 从你的电脑连过去

最简单是 SSH 隧道。在你自己的电脑上：

<Copy id="tunnel" lang="bash" title="开 SSH 隧道" code="ssh -L 8000:127.0.0.1:8000 user@your-vm" />

把 `user@your-vm` 换成你的用户名和服务器地址。然后在本地的 Agent Canvas 里：

1. 打开 `Manage Backends`，点 `Add Backend`。
2. 名字随便起，比如 `my-vm`。
3. 地址填 `http://localhost:8000`。
4. API key 填你存下的那个密钥。
5. 保存，再选中它。

<Callout type="ok">
这个后端显示为已连接。在它上面开的对话，就在服务器上跑。
</Callout>

不想每次开隧道，可以给服务器配一个域名，用 nginx 和 Let's Encrypt 加上 HTTPS。这要再开 80 和 443 端口，443 最好也只允许你的 IP。步骤见官方的 [Self-Hosting Guide](https://github.com/OpenHands/OpenHands/blob/main/docs/SELF_HOSTING.md) 和 [VM / Self-Hosted Installation](https://docs.openhands.dev/openhands/usage/agent-canvas/backend-setup/vm)。

在开到 SSH 隧道以外之前，过一遍这张清单：

- **用 `--public`**，配一个够强的 `LOCAL_BACKEND_API_KEY`。
- **限制谁能连**：防火墙、VPN，或者带登录的代理。
- **能从互联网访问的地址一律用 HTTPS。**
- **限制谁能 SSH 进去**，系统补丁打到最新。
- **保护好这台机器的文件**：设置、密钥、对话和代码都在上面。
- **密钥分享得太广了就换掉。**

## 在手机上看它干活

可以用 Tailscale 把手机和电脑连进同一个私有网络，不用把它开到公网上。实在要用公网地址（比如 ngrok），一定先用 public 模式和强密钥。<u>不加认证就开到公网上，谁拿到地址都能用你的实例和里面的模型 key。</u>具体步骤见[在手机上看它干活](/howto/phone/)。

## 和团队一起用

可以把一个 Agent Server 共享给团队，跑代码审查、依赖升级这类活。你自己的代理照样在笔记本上跑。两个都加进 `Manage Backends`，随时切换。

不想自己管服务器，就用 <Term k="OpenHands Cloud" />。它带团队、权限、用量统计和预算管理。需要自己托管又要商业支持的组织，有 OpenHands Enterprise。见[用 OpenHands Cloud](/howto/cloud/)。

## 让评审员给它打分（Critic）

Critic 会在代理做完后再评一遍，估计这件事做成的可能性，并标出发现的问题。它还在实验阶段，说法和默认值可能会变。

1. 打开 `Settings > Verification`。
2. 打开 `Enable Critic`。
3. 模型用的是 `OpenHands` 服务商的话，`Critic API Key` 留空就行。用别家的话，填一个 OpenHands 的 LLM key。
4. 保存，开一个新对话。

再打开 `Enable Iterative Refinement`，分数太低时它会让代理回去改。官方托管的 Critic 目前免费。它只管 OpenHands 自己的代理，ACP 代理不一定支持。

## 用代码搭自己的代理（SDK）

<Term k="SDK" /> 是一套 Python 和 REST 接口，用来写会处理代码的代理。Agent Canvas 和 OpenHands Cloud 背后都是它。

先装 `uv`：

<Copy id="uv" lang="bash" title="装 uv" code="curl -LsSf https://astral.sh/uv/install.sh | sh" />

再装 SDK。这两个包一定要用**一条**命令一起装，版本才对得上：

<Copy id="sdk" lang="bash" title="装 SDK" code="pip install -U openhands-sdk openhands-tools" />

设好模型 key：

<Copy id="sdk-key" lang="bash" title="设置 key" code="export LLM_API_KEY=your-api-key-here" />

用 OpenHands 的 key 时，这里要填 **LLM API Key**，不是 Cloud API key。模型名用 `openhands/` 开头。第一个示例让代理把当前项目的三个事实写进 `FACTS.txt`，代码见官方的 [Getting Started](https://docs.openhands.dev/sdk/getting-started)。

## 卡住了？

<Q q="浏览器打开域名显示 502 Bad Gateway。">
<p>服务器上 <code>127.0.0.1:8000</code> 的程序停了。看看 <code>npx</code> 那个进程还在不在。</p>
</Q>
<Q q="只想让服务器跑后端，界面留在我电脑上。">
<p>在服务器上用 <code>agent-canvas --backend-only --public</code>，在你电脑上用 <code>agent-canvas --frontend-only</code>，再把服务器加进 <code>Manage Backends</code>。</p>
</Q>
<Q q="SDK 报 Unable to find token in cache。">
<p>你填的多半是 OpenHands Cloud 的 API key。SDK 要用的是 <code>API Keys</code> 页里的 LLM API Key。</p>
</Q>
