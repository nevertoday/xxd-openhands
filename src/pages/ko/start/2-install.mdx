이번 레슨은 세 단계예요. 데스크톱 앱을 설치하고, 처음 열어 보고, 모델 키를 받아요. 데스크톱 앱에는 필요한 게 다 들어 있어서, 다른 걸 따로 설치할 필요가 없어요. 설치가 끝나면, 다음 레슨에서 레슨 1의 물 기록 페이지를 만들게 해요.

## 1단계: 내려받아 설치하기

OpenHands의 [최신 릴리스 페이지](https://github.com/OpenHands/OpenHands/releases/latest)를 열고, 아래로 내려서 **Assets**를 찾은 다음, 내 컴퓨터에 맞는 파일을 내려받으세요. 파일 이름의 버전 번호는 바뀌어요. 지금은 `1.40.0`이에요.

<Tabs id="os" items={[["mac", "Mac"], ["win", "Windows"], ["linux", "Linux"]]}>
<div slot="mac">

1. `OpenHands-Agent-Canvas-1.40.0-universal.dmg` 같은 이름의 파일을 내려받으세요. Apple 실리콘 Mac도 Intel Mac도 이 파일 하나면 돼요.
2. 파일을 열고, **OpenHands Agent Canvas**를 **Applications**(응용 프로그램) 폴더로 끌어다 놓으세요.

</div>
<div slot="win">

1. `OpenHands-Agent-Canvas-Setup-1.40.0.exe` 같은 이름의 파일을 내려받으세요.
2. 실행해서 설치 안내대로 진행하세요.
3. 파란색 SmartScreen 창이 뜰 수 있어요. 그러면 이 파일을 위의 공식 릴리스 페이지에서 받았는지 먼저 확인하고, 계속 진행하세요. 어떤 버튼을 누르라는지는 OpenHands 공식 문서에 없어요. Windows에서는 보통 “추가 정보”를 먼저 눌러야 “실행”이 나타나요.

</div>
<div slot="linux">

- **Ubuntu, Debian:** `agent-canvas_1.40.0_amd64.deb`를 내려받아 패키지 관리자로 설치하세요. 예: `sudo apt install ./agent-canvas_1.40.0_amd64.deb`
- **다른 배포판:** `OpenHands.Agent.Canvas-1.40.0.AppImage`를 내려받고, 파일 관리자의 권한 설정에서 프로그램으로 실행할 수 있게 허용하세요(또는 `chmod +x` 실행). 그다음 더블클릭하세요.

</div>
</Tabs>

<Callout type="ok">
Mac의 응용 프로그램 폴더, Windows의 시작 메뉴, Linux의 애플리케이션 메뉴에 **OpenHands Agent Canvas**가 생겼어요.
</Callout>

## 2단계: 처음 열어 보기

**OpenHands Agent Canvas**를 여세요.

먼저 작은 창이 떠요. `Starting services`(서비스 시작 중)라고 쓰여 있어요. 그 아래 줄에는, 처음 열 때 Python과 OpenHands의 에이전트 서버를 내려받는다고 쓰여 있어요. 새 컴퓨터에서는 몇 분 걸려요. 닫지 말고 기다리세요.

<Callout type="ok">
작은 창이 사라지고 큰 창이 열려요. 가운데에 설정 마법사가 있어요. 제목은 `Check your backend`(백엔드 확인)이나 `Choose your agent`(에이전트 선택)예요.

**여기서 멈추고, 아직 아무것도 누르지 마세요.** 창은 열어 둔 채로 3단계로 가세요. 마법사는 다음 레슨에서 진행해요.
</Callout>

### Mac에서 앱이 “손상되었다”거나 “열 수 없다”고 할 때

데스크톱 앱은 아직 Apple의 서명을 받지 않아서, Mac이 막을 수 있어요. 먼저 공식 릴리스 페이지에서 받은 파일인지 확인하세요. 그다음 이렇게 하세요.

1. Command + 스페이스를 누르고, “터미널”을 입력하고, Return을 누르세요. <Term k="终端" />이 열려요.
2. 아래 한 줄을 복사해서 터미널 창에 붙여 넣고, Return을 누르세요.

<Cmd c='xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app"' />

3. 응용 프로그램 폴더로 돌아가서 **OpenHands Agent Canvas**를 다시 여세요.

<Callout type="ok">
터미널에 아무것도 나오지 않고 새 줄로 넘어가기만 해요. 그러면 성공이에요. 앱을 다시 열면 `Starting services`라고 쓰인 작은 창이 떠요.
</Callout>

## 3단계: OpenHands Cloud 키 받기

<Callout type="tip" title="이미 키나 구독이 있다면 이 단계는 건너뛰세요">
Anthropic, OpenAI, Google 같은 제공업체의 API 키가 이미 있다면, 여기서 돈을 낼 필요가 없어요. 다음 레슨에서 모델을 설정할 때 `LLM Provider`(모델 제공업체)를 내 제공업체로 바꾸고, 내 키를 붙여 넣으면 돼요.

이 컴퓨터에서 Claude Code, Codex, Gemini CLI 구독에 로그인해 있다면 이 단계도 건너뛰고, [전체 가이드 4단계(영어)](/en/guide/4-agents/)를 따라 연결하면 돼요.
</Callout>

이 키가 있으면 OpenHands가 OpenHands Cloud에서 제공하는 모델을 쓸 수 있어요. 아래 버튼 이름은 공식 문서에서 가져왔어요. 사이트 디자인이 바뀔 수 있으니, 가장 비슷한 걸 찾으면 돼요.

1. 브라우저에서 [app.all-hands.dev](https://app.all-hands.dev)를 여세요.
2. `Log in with GitHub`(GitHub로 로그인)를 누르고, GitHub 페이지에서 접근을 허용하세요.
3. 이용 약관(`terms of service`)을 읽고 동의한 다음, `Continue`(계속)를 누르세요.
4. `Settings`(설정)의 `Billing`(결제)을 열고, 최소 10달러를 충전하세요. 공식 문서에 따르면, 이게 없으면 다음 단계에서 키를 받을 수 없어요.
5. `Settings`의 `API Keys`를 열고, `OpenHands LLM Key` 칸을 찾으세요. 당신의 키가 거기 있어요.

<Callout type="ok">
`API Keys` 페이지에 `OpenHands LLM Key` 칸이 있어요.

**이 페이지는 열어 두세요.** 다음 레슨에서 여기서 키를 복사해요.
</Callout>

같은 페이지에 `Create API Key` 버튼도 있어요. <u>이건 누르지 마세요. 프로그램용으로 쓰는 다른 종류의 키를 만들어요. 데스크톱 앱에서는 쓸 수 없어요.</u> 필요한 건 `OpenHands LLM Key` 칸에 이미 있는 키예요.

<Callout type="warn">
이 키는 출입 카드 같은 거예요. 절대 남에게 주거나 채팅에 붙여 넣지 마세요. 유출됐다면 `Refresh API Key`를 눌러 새 키를 받으세요. 그러면 예전 키는 더 이상 쓸 수 없어요.
</Callout>

## 뭔가 이상할 때

<Q q="Assets 아래에 파일이 너무 많아서 뭘 받아야 할지 모르겠어요.">
<p>이름의 끝부분만 보세요. Mac은 `.dmg`, Windows는 `.exe`, Ubuntu는 `.deb`, 다른 Linux는 `.AppImage`예요. 나머지는 신경 쓰지 않아도 돼요.</p>
</Q>
<Q q="몇 분째 Starting services에서 멈춰 있어요.">

처음 열 때는 내려받는 게 있어서, 인터넷이 느리면 더 오래 걸려요. 조금 더 기다려 보세요.

그래도 그대로라면, 작은 창의 `Show details`(자세히 보기)를 눌러 시작 로그를 펼치세요. 로그 위의 `Copy`(복사)를 눌러 복사한 다음, [OpenHands 이슈 페이지](https://github.com/OpenHands/OpenHands/issues)에서 새 이슈를 열고 붙여 넣으세요.

</Q>
<Q q="작은 창에 긴 로그가 나오고 나서 멈췄어요.">
<p>시작에 실패해서 로그를 보여 주는 거예요. `Copy`를 눌러 로그를 복사하고, `Quit`(종료)을 누른 다음, 앱을 다시 여세요. 또 그러면 로그를 [OpenHands 이슈 페이지](https://github.com/OpenHands/OpenHands/issues)에 붙여 넣으세요.</p>
</Q>
<Q q="GitHub 계정이 없어요.">
<p>로그인 페이지에는 `Log in with GitLab`과 `Log in with Bitbucket`도 있어요. 있는 걸로 쓰면 돼요. 하나도 없다면 먼저 [github.com](https://github.com)에서 가입하세요.</p>
</Q>
<Q q="API Keys 페이지에 OpenHands LLM Key가 없거나, 키를 받을 수 없어요.">
<p>아마 아직 충전하지 않았을 거예요. `Settings`의 `Billing`에서 최소 10달러를 충전한 다음, `API Keys`를 다시 확인하세요.</p>
</Q>
<Q q="데스크톱 앱 말고 명령줄로 설치하고 싶어요.">
<p>npm과 Docker로 설치하는 방법은 [전체 가이드의 설치 단계(영어)](/en/guide/1-install/)에 있어요. 이 레슨에서는 데스크톱 앱이면 충분해요.</p>
</Q>
<Q q="그만 쓰고 싶나요? 종료, 업데이트, 삭제하는 법">
<ul><li>**종료:** 앱 메뉴에서 **OpenHands Agent Canvas**를 종료하세요. 다시 쓰고 싶으면 그냥 열면 돼요.</li><li>**업데이트:** 최신 설치 파일을 내려받아 다시 설치하세요. `Settings`의 `Application`(애플리케이션) 페이지에서도 버전을 보고 업데이트를 확인할 수 있어요.</li><li>**삭제:** 먼저 종료하세요. Mac에서는 응용 프로그램 폴더에서 휴지통으로 끌어다 놓으세요. Windows에서는 **설치된 앱**에서 제거하세요. Linux에서는 AppImage 파일을 지우거나 deb 패키지를 제거하세요.</li></ul>
</Q>

<Callout type="tip" title="다음 레슨">
설치도 끝났고 모델도 준비됐어요. 다음 레슨에서는 설정 마법사를 마치고, 메시지 하나를 쓰고, 레슨 1의 물 기록 페이지가 만들어지는 걸 지켜봐요.
</Callout>
