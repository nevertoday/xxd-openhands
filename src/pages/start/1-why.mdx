## 你平时用 AI 可能是这样

你让 AI 做一个记录每天喝了几杯水的小网页。它回你一大段代码。

接下来全靠你：新建文件、粘贴、保存、打开。打不开，再把报错复制回去问它。来回好几轮。

## OpenHands 自己动手

<Term k="OpenHands" /> 是一个会自己动手的 AI，也叫<Term k="代理" />。你说要什么，它自己做：

- **建文件、改文件。** 代码它自己写进文件里。
- **运行命令。** 需要装什么、跑什么，它自己在电脑上敲。
- **自己试。** 跑起来看看，出错了接着改。

你在旁边看着它一步步做，最后自己打开结果检查。还是那个喝水的小网页，交给 OpenHands 是这样的：

<Demo />

这只是开头。用熟了，它能同时开好几个代理各干各的，按时间自己开工，同事在 Slack、GitHub 里叫一声它就动手。新手课先把第一件事做成。

## 你要准备什么

- **一台电脑。** Mac（Apple 芯片和 Intel 都行）、Windows 或 Linux（x64）都可以。
- **一个模型。** OpenHands 自己不带「大脑」，要接一个<Term k="模型" />。你已经有的 <Term k="API key" /> 或订阅就能用，下面「花什么钱」细说。什么都没有的，下一课一步步拿一个 <Term k="OpenHands Cloud" /> 的 key。
- **一个 GitHub 账号。** 只有走 OpenHands Cloud 这条路才要，用来登录。

不需要会编程，一般也用不着命令行。

## 花什么钱

OpenHands 本身免费，它是开源软件（MIT 许可）。花钱的是模型：用多少扣多少，任务越长、来回越多，扣得越多。看你手上有什么：

| 你手上有 | 要不要另外花钱 |
|:---|:---|
| 服务商的 API key（Anthropic、OpenAI、Google 这些给的） | 不用。直接填进去用，照那家的价格扣 |
| 这台电脑上登录了 Claude Code、Codex 或 Gemini CLI 的订阅 | 不用。接进来用你已经付过的订阅，[完整教程第 4 步](/guide/4-agents/)讲怎么接 |
| 什么都没有 | 新手课带你走 OpenHands Cloud。官方文档写着：拿 key 之前，要先买至少 10 美元的额度 |

<Q q="走 OpenHands Cloud 的话，这 10 美元会被花掉吗？">
<p>不一定。Cloud 上有一个免费模型，在模型列表里标着 `Free`，用它不扣额度。写这篇时是 DeepSeek V4 Flash。免费的是哪个会变，以列表里的 `Free` 标记为准。只要一直选它，这笔额度不会被用掉。</p>
</Q>

## 有什么风险

在你自己的电脑上，它用的是你这个账号的权限。你能读写的文件，它都能读写；你能运行的命令，它也能运行。它默认不会每一步都先问你。

所以新手课只做一件事来防：<mark><strong>给它一个新建的空文件夹，让它只在里面干活。</strong></mark>

这个文件夹不是锁，只是它干活的地方。我们会在给它的话里写明「只动这个文件夹」。想把它彻底关进一个隔离的小房间（<Term k="Docker" />），完整教程里讲。

桌面版现在还是预览版，可能有些小毛病。
