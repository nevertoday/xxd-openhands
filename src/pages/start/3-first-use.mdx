这一课让 OpenHands 做一个真的小东西：一个记录每天喝了几杯水的网页。

桌面版的界面默认是英文。下面每个按钮都照屏幕上的英文写，后面括号里是意思。想换成中文，看页尾「不对怎么办」的最后一条。

## 先建一个空文件夹

在桌面上新建一个文件夹，名字叫 `water`。里面什么都不要放。

这就是它的<Term k="工作区" />：它在这里建文件、改文件。

<Callout type="ok">
桌面上有一个空的 `water` 文件夹。
</Callout>

## 走完设置向导

回到上一课开着的 **OpenHands Agent Canvas** 窗口。向导有三到四屏，最上面有一条进度条。

### 如果看到 Check your backend（检查后端）

这一屏在确认它的后台程序已经跑起来了。桌面版会自己启动它，所以很多时候这一屏会直接跳过。

<Callout type="ok">
写着 `You're connected!`（已连接）。点 `Next`（下一步）。
</Callout>

### Choose your agent（选择智能体）

列表里第一个是 **OpenHands**，已经选好了。别的不用看，直接点 `Next`。

<Callout type="ok">
标题变成 `Set up your LLM`（设置模型）。
</Callout>

### Set up your LLM（设置模型）

1. **LLM Provider**（模型提供方）：保持 `OpenHands`，不用改。
2. **LLM Model**（模型）：点开列表，选一个后面标着 `Free` 的。写这篇时是 DeepSeek V4 Flash。它默认选的那个要扣额度，所以记得换。
3. **API Key**：回到上一课开着的 OpenHands Cloud 网页。复制 `OpenHands LLM Key` 那一栏的 key，粘贴到这里。
4. 其他格子不用动，点 `Next`。

用自己服务商 key 的：`LLM Provider` 选你那家（比如 Anthropic），`LLM Model` 选那家的模型，`API Key` 贴你自己的 key。这时没有 `Free` 的模型，照那家的价格扣钱。

<Callout type="ok">
标题变成 `Say hello`（打个招呼），下面有一个输入框。
</Callout>

### Say hello（打个招呼）：先别在这里发

在这里发消息，会开一个没有工作区的新对话。它不知道该去 `water` 文件夹。

所以这里什么都不发，点最下面的 `Close`（关闭）。

<Callout type="ok">
向导关掉了。窗口中间写着 `What do you want to work on?`（你想做什么？），下面是一个大输入框。左边栏可能多了一个 `Getting started` 清单，可以不管它。
</Callout>

## 打开空文件夹

1. 在大输入框下面，点带文件夹图标的 `Open Workspace`（打开工作区）。
2. 弹出的窗口里，点 `Select a workspace`（选择工作区），再点 `+ Add Workspace`（添加工作区）。
3. 又弹出一个 `Add workspaces` 窗口，里面列着你电脑上的文件夹。点 `Desktop`（桌面），再点 `water`。
4. 点 `Add this directory`（添加这个文件夹）。这个窗口会自己关掉。
5. 回到 `Open Workspace` 窗口，点 `Confirm`（确认）。

<Callout type="ok">
大输入框下面原来写着 `Open Workspace` 的地方，现在写着 `water`。
</Callout>

## 把这段话发给它

<Copy id="first" title="复制，粘贴进大输入框，按回车" code={`我想要：一个记录每天喝了几杯水的小网页。这是一个空文件夹，所有文件都建在这里面，不要动这个文件夹以外的东西。
做好是什么样子：我打开网页，点一下「喝了一杯」，今天的杯数加一；关掉再打开，数字还在；页面上能看到最近 7 天每天喝了几杯。
做完给我看：你做了哪些检查，每一项看到了什么结果。最后告诉我，双击哪个文件能打开这个网页。`} />

这段话只有三部分，以后交代任何事都用这个样子：

<mark><strong>我想要什么 · 做好是什么样子 · 做完给我看什么</strong></mark>

- **我想要什么：** 一个记录喝水的网页，只在这个文件夹里做。
- **做好是什么样子：** 点了会加一，关掉再开还在，能看到 7 天。它会照着这几条去试。
- **做完给我看什么：** 它检查了什么、看到了什么。你不用看懂代码，看这些就够了。

<Callout type="ok">
你的话出现在对话里，下面先显示启动的进度。接着出现一行 `Thinking`（思考中），再往后是它做的事。
</Callout>

## 看它干活

它会自己干上几分钟。默认它不会停下来问你「可以运行这个命令吗」，会一路做下去。

它每做完一段，对话里就多一行总结，比如：

- `Ran a command`：运行了一条命令。
- `Made an edit`：改了一处文件。
- `Read a file`：看了一个文件。

正在做的那一段排在最下面，写着它当前在做哪一步，或者 `Thinking`。这些看不懂可以不看，等它停下来写回复。

最后它会写一段回复，大概是这个样子：

<Reply code={`① 做了什么：在 water 文件夹里建了 index.html，
   打开就是记录喝水的页面。

② 检查结果
   ✓ 点了 3 次「喝了一杯」，今天显示 3 杯
   ✓ 关掉页面再打开，还是 3 杯
   ✓ 最近 7 天每天一格，今天这格是 3
   ? 没法确定：手机上的样子，我只在电脑上检查了

③ 怎么打开：双击 water 文件夹里的 index.html`} />

- **①** 看它做的是不是你要的。
- **②最重要。** 每一条都写着它做了什么、看到了什么。写着「没法确定」的那条，是它在说实话。
- **③** 照着做，自己打开看一眼。

## 自己检查一遍

1. 打开桌面上的 `water` 文件夹，双击它说的那个文件。
2. 照你写的三条亲手试一遍：点几下、关掉再打开、看看 7 天。

然后问自己三个问题：

- 它做的，是我要的那个东西吗？
- 它说做完的时候，列出了实际做过的检查和结果吗？
- 我自己打开试，和它说的一样吗？

三个都是「是」，这件事就做好了。

如果它只说了一句「完成了」，没有任何检查结果，就回它：

<Copy id="no-proof" code="给我看你实际检查的结果：做了哪些操作，看到了什么。不要只说做完了。" />

## 想让它停下

它在干活时，输入框旁边有一个暂停图标（两条竖线）的按钮，这就是 `Stop`（停止）。点它，它就停下了。

<Callout type="ok">
它不再往下做，状态写着 `Stopped`（已停止）。
</Callout>

停下以后，在输入框里打字告诉它你想要什么，比如「只做喝水记录，别的先不加」。按回车，它会接着做。

## 不对怎么办

<Q q="在 Set up your LLM 那一屏点 Next，弹出错误，进不了下一屏。">
<p>它保存之前会先试一下这个 key，试不通就不让过。回 OpenHands Cloud 的 `API Keys` 页面，重新复制 `OpenHands LLM Key` 那一栏的 key 再粘贴。别用 `Create API Key` 生成的那种。</p>
</Q>
<Q q="模型列表里没有标着 Free 的。">
<p>免费的模型会换，有时一个都没有。这时选别的模型也能用，只是会扣你充的额度。</p>
</Q>
<Q q="向导被我关了，或者重新打开软件以后没再出现。">
<p>点左边栏的 `Settings`（设置），再点 `LLM`，新加一个模型设置。在 `Basic`（基础）那一页选 `OpenHands`，选标着 `Free` 的模型，粘贴 key，保存。</p>
</Q>
<Q q="首页的大输入框是灰的，打不了字。">
<p>多半是模型还没设好。照上一条，去 `Settings` 里的 `LLM` 填好再回来。</p>
</Q>
<Q q="Add workspaces 窗口里找不到桌面。">
<p>它在这里叫 `Desktop`，不叫「桌面」。有的 Windows 电脑，桌面放在 OneDrive 里，这时先点 `OneDrive`，再找 `Desktop`。</p>
</Q>
<Q q="它说找不到文件夹，或者文件没出现在 water 里。">
<p>多半是发消息之前没打开工作区。在左边栏开一个新对话，先照「打开空文件夹」做一遍。看到输入框下面写着 `water`，再把那段话发出去。</p>
</Q>
<Q q="我的消息旁边出现 Failed to send。">
<p>网慢的时候会这样。等一会儿，消息出现在对话里了就不用管。一直没出现，点 `Retry`（重试）。</p>
</Q>
<Q q="做出来不对，比如点了按钮数字没变。">
<p>只说你看到的，比如：「我点了三次，数字一直是 0。」不用猜原因，猜错了会把它带偏。</p>
</Q>
<Q q="它问了我一个看不懂的问题。">
<p>直接回它：「我不会编程，请用大白话问我；或者你替我选一个最稳妥的，并告诉我为什么。」</p>
</Q>
<Q q="想把界面换成中文。">
<p>点 `Settings`，再点 `Application`（应用程序），在 `Language`（语言）里选「简体中文」，点 `Save Changes`（保存更改）。</p>
</Q>

## 你已经会了

以后做任何事，都是同一个样子：先打开一个文件夹，再发三部分的话。比如：

<Copy id="ex-card" title="再做一个小东西" code={`我想要：一张生日贺卡网页，打开时有一句「生日快乐」，点一下会换一种颜色。这是一个空文件夹，所有文件都建在这里面。
做好是什么样子：打开网页能看到这句话；点一下颜色会变；连点五次，颜色每次都不一样。
做完给我看：你做了哪些检查，看到了什么结果。最后告诉我双击哪个文件打开。`} />

每做一件新事，就新建一个空文件夹，在新的<Term k="对话" />里打开它。
