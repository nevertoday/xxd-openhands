Здесь всего три шага: установить приложение, открыть его в первый раз и получить ключ к модели. Всё нужное приложение приносит с собой, так что больше ничего ставить не придётся. А когда приложение будет установлено, в следующем уроке OpenHands сделает страницу для учёта воды из урока 1.

## Шаг 1. Скачайте и установите

Откройте [последний выпуск OpenHands](https://github.com/OpenHands/OpenHands/releases/latest), прокрутите вниз до раздела **Assets** (файлы) и скачайте файл для своего компьютера. Номер версии в имени файла меняется. Сейчас это `1.40.0`.

<Tabs id="os" items={[["mac", "Mac"], ["win", "Windows"], ["linux", "Linux"]]}>
<div slot="mac">

1. Скачайте файл с именем вроде `OpenHands-Agent-Canvas-1.40.0-universal.dmg`. Он один и тот же для Mac на Apple silicon и на Intel.
2. Откройте его и перетащите **OpenHands Agent Canvas** в папку **Applications** («Программы»).

</div>
<div slot="win">

1. Скачайте файл с именем вроде `OpenHands-Agent-Canvas-Setup-1.40.0.exe`.
2. Запустите его и следуйте подсказкам установщика.
3. Может появиться синее окно SmartScreen. Если так, убедитесь, что файл скачан с официальной страницы выпуска выше, и продолжайте. В документации OpenHands не сказано, какие кнопки нажимать. Обычно в Windows сначала нужно нажать «Подробнее», и тогда появится «Выполнить в любом случае».

</div>
<div slot="linux">

- **Ubuntu или Debian:** скачайте `agent-canvas_1.40.0_amd64.deb` и установите его менеджером пакетов, например `sudo apt install ./agent-canvas_1.40.0_amd64.deb`.
- **Другие дистрибутивы:** скачайте `OpenHands.Agent.Canvas-1.40.0.AppImage` и в свойствах файла в файловом менеджере разрешите запускать его как программу (или выполните для него `chmod +x`). Потом откройте его двойным щелчком.

</div>
</Tabs>

<Callout type="ok">
**OpenHands Agent Canvas** появился в папке «Программы» на Mac, в меню «Пуск» на Windows или в меню приложений на Linux.
</Callout>

## Шаг 2. Откройте его в первый раз

Откройте **OpenHands Agent Canvas**.

Сначала появится маленькое окно с надписью `Starting services` («запуск служб»). Строка под ней говорит, что при первом запуске скачиваются Python и сервер агента OpenHands. На новом компьютере это занимает несколько минут. Просто подождите и не закрывайте окно.

<Callout type="ok">
Маленькое окно исчезает, и открывается большое с мастером настройки посередине. Его заголовок — `Check your backend` («проверьте бэкенд») или `Choose your agent` («выберите агента»).

**Остановитесь здесь и пока ничего не нажимайте.** Оставьте окно открытым и переходите к шагу 3. Мастер вы пройдёте в следующем уроке.
</Callout>

### Mac пишет, что приложение повреждено или его нельзя открыть

Приложение пока не подписано Apple, поэтому Mac может его заблокировать. Сначала убедитесь, что скачали его с официальной страницы выпуска. Потом:

1. Нажмите Command + пробел, введите «Терминал» и нажмите Return. Откроется <Term k="终端" />.
2. Скопируйте эту строку, вставьте её в окно терминала и нажмите Return:

<Cmd c='xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app"' />

3. Вернитесь в «Программы» и снова откройте **OpenHands Agent Canvas**.

<Callout type="ok">
Терминал ничего не выводит и просто переходит на новую строку. Значит, всё получилось. При новом запуске приложения появляется маленькое окно `Starting services`.
</Callout>

## Шаг 3. Получите ключ OpenHands Cloud

<Callout type="tip" title="Уже есть ключ или подписка? Пропустите этот шаг">
Если у вас уже есть API-ключ от провайдера вроде Anthropic, OpenAI или Google, здесь ничего платить не нужно. В следующем уроке, когда будете настраивать модель, переключите `LLM Provider` (поставщик модели) на своего провайдера и вставьте свой ключ.

Если на этом компьютере вы вошли в подписку Claude Code, Codex или Gemini CLI, этот шаг тоже можно пропустить и подключить подписку по [шагу 4 полного руководства (на английском)](/en/guide/4-agents/).
</Callout>

Этот ключ позволяет OpenHands пользоваться моделями, которые предоставляет OpenHands Cloud. Названия кнопок ниже взяты из официальной документации. Сайт может поменять оформление, так что ищите самое похожее.

1. Откройте в браузере [app.all-hands.dev](https://app.all-hands.dev).
2. Нажмите `Log in with GitHub` («войти через GitHub») и подтвердите доступ на странице GitHub.
3. Прочитайте условия использования (`terms of service`), примите их и нажмите `Continue` («продолжить»).
4. Откройте `Billing` («оплата») в разделе `Settings` («настройки») и пополните счёт хотя бы на $10. В официальной документации сказано, что без этого ключ на следующем шаге не получить.
5. Откройте `API Keys` в разделе `Settings` и найдите блок `OpenHands LLM Key`. Ваш ключ там.

<Callout type="ok">
На странице `API Keys` есть блок `OpenHands LLM Key`.

**Не закрывайте эту страницу.** В следующем уроке вы скопируете ключ отсюда.
</Callout>

На той же странице есть кнопка `Create API Key` («создать API-ключ»). <u>Не нажимайте её. Она создаёт другой вид ключа, для программ. В приложении он не сработает.</u> Вам нужен ключ, который уже лежит в блоке `OpenHands LLM Key`.

<Callout type="warn">
Этот ключ — как пропуск. Никому его не передавайте и не вставляйте в чаты. Если он утёк, нажмите `Refresh API Key` («обновить API-ключ»), чтобы получить новый, и старый перестанет работать.
</Callout>

## Если что-то не так

<Q q="В разделе Assets много файлов, и я не знаю, какой скачать.">
<p>Смотрите только на конец имени. Для Mac берите `.dmg`, для Windows — `.exe`, для Ubuntu — `.deb`, для другого Linux — `.AppImage`. Остальное не трогайте.</p>
</Q>
<Q q="Уже несколько минут висит Starting services.">

При первом запуске приложение кое-что скачивает, поэтому на медленном интернете это дольше. Подождите ещё немного.

Если всё равно ничего не меняется, нажмите `Show details` («показать подробности») в маленьком окне, чтобы открыть журнал запуска. Нажмите `Copy` («копировать») над журналом, затем создайте новую заявку на [странице issues OpenHands](https://github.com/OpenHands/OpenHands/issues) и вставьте его туда.

</Q>
<Q q="В маленьком окне появился длинный журнал, и всё остановилось.">
<p>Запуск не удался, и окно показывает вам журнал. Нажмите `Copy`, чтобы скопировать журнал, нажмите `Quit` («выйти») и откройте приложение снова. Если это повторится, вставьте журнал на [странице issues OpenHands](https://github.com/OpenHands/OpenHands/issues).</p>
</Q>
<Q q="У меня нет аккаунта GitHub.">
<p>На странице входа есть ещё `Log in with GitLab` и `Log in with Bitbucket`. Выберите то, что у вас есть. Если нет ничего, сначала зарегистрируйтесь на [github.com](https://github.com).</p>
</Q>
<Q q="На странице API Keys нет OpenHands LLM Key, или я не могу получить ключ.">
<p>Скорее всего, вы ещё не пополнили счёт. Откройте `Billing` в разделе `Settings`, пополните счёт хотя бы на $10 и снова загляните в `API Keys`.</p>
</Q>
<Q q="Не хочу приложение. Хочу установить из командной строки.">
<p>Установка через npm и Docker описана в [шаге установки полного руководства (на английском)](/en/guide/1-install/). Для этих уроков достаточно приложения.</p>
</Q>
<Q q="Хотите перестать им пользоваться? Как закрыть, обновить или удалить">
<ul><li>**Закрыть:** выйдите из **OpenHands Agent Canvas** через меню приложения. Чтобы снова пользоваться, просто откройте его.</li><li>**Обновить:** скачайте последний установщик и установите заново. Страница `Application` («приложение») в разделе `Settings` тоже показывает версию и умеет проверять обновления.</li><li>**Удалить:** сначала закройте приложение. На Mac перетащите его из «Программ» в Корзину. На Windows удалите его в разделе **Установленные приложения**. На Linux удалите файл AppImage или пакет deb.</li></ul>
</Q>
