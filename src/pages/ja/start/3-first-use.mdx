このレッスンでは、OpenHands に小さくても本物のものを作ってもらいます。毎日コップ何杯の水を飲んだかを記録するウェブページです。

デスクトップアプリの画面は英語です。このページでは、ボタン名は画面のとおり英語で書き、かっこの中に意味を添えます。

## まず、空のフォルダを作る

デスクトップに `water` という名前の新しいフォルダを作ります。中には何も入れません。

これが OpenHands の<Term k="工作区" />です。ここでファイルを作ったり書き換えたりします。

<Callout type="ok">
デスクトップに、空の `water` フォルダがあります。
</Callout>

## 設定ウィザードを終える

前のレッスンで開いたままにした **OpenHands Agent Canvas** のウィンドウに戻ります。ウィザードは 3〜4 画面で、いちばん上に進み具合のバーがあります。

### Check your backend（バックエンドの確認）が出たら

この画面は、裏で動くサービスが起動しているかを確かめています。デスクトップアプリが自分で起動してくれるので、この画面は飛ばされることもよくあります。

<Callout type="ok">
`You're connected!`（接続しました）と表示されています。`Next`（次へ）を押します。
</Callout>

### Choose your agent（エージェントの選択）

いちばん上の **OpenHands** が、もう選ばれています。ほかは気にせず `Next` を押します。

<Callout type="ok">
タイトルが `Set up your LLM`（モデルの設定）に変わります。
</Callout>

### Set up your LLM（モデルの設定）

1. **LLM Provider**（モデルの提供元）：`OpenHands` のままにします。
2. **LLM Model**（モデル）：一覧を開いて、`Free` と書かれたものを選びます。この記事を書いた時点では DeepSeek V4 Flash です。最初から選ばれているモデルはクレジットを使うので、必ず切り替えてください。
3. **API Key**：開いたままにしておいた OpenHands Cloud のページに戻ります。`OpenHands LLM Key` の欄のキーをコピーして、ここに貼り付けます。
4. ほかの欄はそのままにして、`Next` を押します。

自分のプロバイダーのキーを使う場合は、`LLM Provider`（モデルの提供元）を自分のプロバイダー（たとえば Anthropic）にし、`LLM Model`（モデル）でそのモデルを 1 つ選び、`API Key` に自分のキーを貼り付けます。この場合 `Free` のモデルはありません。使った分は、そのプロバイダーの料金で請求されます。

<Callout type="ok">
タイトルが `Say hello`（あいさつ）に変わり、下に入力欄があります。
</Callout>

### Say hello（あいさつ）：ここでは何も送らない

ここからメッセージを送ると、ワークスペースのない新しい会話が始まります。`water` フォルダを使えばいいことがわかりません。

なので、ここでは何も送りません。下の `Close`（閉じる）を押します。

<Callout type="ok">
ウィザードが閉じます。ウィンドウの真ん中に `What do you want to work on?`（何をしますか？）と表示され、その下に大きな入力欄があります。左のサイドバーに `Getting started` のチェックリストが出ることがありますが、気にしなくて大丈夫です。
</Callout>

## 空のフォルダを開く

1. 大きな入力欄の下にある、フォルダのアイコンのボタン `Open Workspace`（ワークスペースを開く）を押します。
2. 開いたウィンドウで `Select a workspace`（ワークスペースを選ぶ）を押し、次に `+ Add Workspace`（ワークスペースを追加）を押します。
3. `Add workspaces` のウィンドウが開き、パソコンの中のフォルダが並びます。`Desktop`（デスクトップ）を押し、次に `water` を押します。
4. `Add this directory`（このフォルダを追加）を押します。このウィンドウは自動で閉じます。
5. `Open Workspace` のウィンドウに戻ったら、`Confirm`（確定）を押します。

<Callout type="ok">
大きな入力欄の下、`Open Workspace` と書かれていたところが `water` に変わっています。
</Callout>

## このメッセージを送る

<Copy id="first" title="コピーして大きな入力欄に貼り付け、Enter" code={`ほしいもの：毎日コップ何杯の水を飲んだかを記録する、小さなウェブページ。ここは空のフォルダです。ファイルはすべてこの中に作り、このフォルダの外には一切触れないでください。
できあがりの姿：ページを開いて「1 杯飲んだ」を押すと、今日の杯数が 1 つ増える。閉じてもう一度開いても数字が残っている。最近 7 日間、毎日何杯飲んだかがページに表示される。
終わったら見せてほしいもの：何を確かめたか、それぞれ何が見えたか。最後に、どのファイルをダブルクリックすればページが開くか教えてください。`} />

このメッセージは 3 つの部分だけでできています。何を頼むときも、同じ形で書きます。

<mark><strong>ほしいもの · できあがりの姿 · 終わったら見せてほしいもの</strong></mark>

- **ほしいもの：** 水を記録するページ。このフォルダの中だけで作る。
- **できあがりの姿：** 押すと 1 つ増える、閉じて開いても残っている、7 日分が見える。OpenHands はこの 1 つずつを試します。
- **終わったら見せてほしいもの：** 何を確かめて、何が見えたか。コードは読まなくて大丈夫です。これで十分です。

<Callout type="ok">
あなたのメッセージが会話に表示され、その下に起動の進み具合が出ます。続いて `Thinking`（考え中）の行が出て、そのあとに OpenHands がしたことが並びます。
</Callout>

## 作業を見守る

数分間、自分で作業します。初期設定では「このコマンドを実行してもいいですか？」と止まって聞いたりせず、そのまま進めます。

ひとまとまりの作業が終わるたびに、会話に 1 行のまとめが出ます。たとえば：

- `Ran a command`：コマンドを実行した。
- `Made an edit`：ファイルを書き換えた。
- `Read a file`：ファイルを読んだ。

いま作業中のまとまりは、いちばん下にあります。いまのステップか `Thinking` が表示されます。ここは読み飛ばして、返事を待つだけでもかまいません。

最後に返事を書きます。だいたいこんな形です。

<Reply code={`① したこと：water フォルダに index.html を作りました。
   開くと水の記録ページが表示されます。

② 確かめたこと
   ✓「1 杯飲んだ」を 3 回押した → 今日は 3 杯と表示
   ✓ ページを閉じてもう一度開いた → 3 杯のまま
   ✓ 最近 7 日間、1 日 1 マス → 今日のマスは 3
   ? 確かめられなかったこと：スマホでの見え方（パソコンでしか確かめていません）

③ 開き方：water フォルダの index.html をダブルクリック`} />

- **①：** 頼んだものになっているか見ます。
- **② がいちばん大事です。** 1 行ずつ、何をして何が見えたかが書いてあります。「確かめられなかったこと」の行は、正直に言ってくれている証拠です。
- **③：** そのとおりにして、自分の目で見ます。

## 自分で確かめる

1. デスクトップの `water` フォルダを開き、言われたファイルをダブルクリックします。
2. 書いた 3 つの点を自分の手で試します。何回か押す、閉じてまた開く、7 日分を見る。

それから、自分に 3 つ聞いてみてください。

- 作ってくれたものは、頼んだものですか？
- 「できました」と言ったとき、実際にした確認と、見えたものを並べていましたか？
- 自分で試してみて、言っていたとおりでしたか？

3 つとも「はい」なら、この仕事は完了です。

もし「できました」とだけ言って、確認の結果が何もなければ、こう返します。

<Copy id="no-proof" code="実際に確かめた結果を見せてください。何をして、何が見えたか。「できました」とだけ言わないでください。" />

## 止めたいとき

作業中は、入力欄の横に一時停止のアイコン（縦線 2 本）のボタンがあります。これが `Stop`（停止）です。押すと止まります。

<Callout type="ok">
作業が止まり、状態が `Stopped`（停止しました）になります。
</Callout>

止めたあとは、入力欄に何をしてほしいかを書きます。たとえば「水の記録だけにして、ほかは今はいりません」。Enter を押すと、そこから続けます。

## うまくいかないとき

<Q q="Set up your LLM で Next を押すと、次の画面ではなくエラーが出る。">
<p>保存する前にキーを試していて、うまくいかないと先へ進めません。OpenHands Cloud の `API Keys` のページに戻り、`OpenHands LLM Key` の欄のキーをもう一度コピーして貼り付けてください。`Create API Key` で作ったキーは使わないでください。</p>
</Q>
<Q q="モデルの一覧に Free と書かれたものがない。">
<p>無料のモデルは入れ替わりますし、1 つもないときもあります。ほかのモデルでも使えますが、チャージしたクレジットが減ります。</p>
</Q>
<Q q="ウィザードを閉じてしまった。またはアプリを開き直したら出てこない。">
<p>左のサイドバーの `Settings`（設定）を押し、`LLM` を押して、モデルの設定を新しく追加します。`Basic`（基本）のタブで `OpenHands` を選び、`Free` と書かれたモデルを選んで、キーを貼り付けて保存します。</p>
</Q>
<Q q="ホーム画面の大きな入力欄が灰色で、文字が打てない。">
<p>たぶん、まだモデルの設定ができていません。ひとつ前の答えのとおりに設定してから戻ってきてください。</p>
</Q>
<Q q="Add workspaces のウィンドウでデスクトップが見つからない。">
<p>ここでは「デスクトップ」ではなく `Desktop` と表示されています。Windows のパソコンによっては、デスクトップが OneDrive の中にあります。その場合は先に `OneDrive` を押してから、`Desktop` を探してください。</p>
</Q>
<Q q="フォルダが見つからないと言われる。または water にファイルができていない。">
<p>たぶん、ワークスペースを開く前にメッセージを送ってしまいました。左のサイドバーから新しい会話を始め、「空のフォルダを開く」をもう一度やってください。入力欄の下に `water` と出てから、メッセージを送ります。</p>
</Q>
<Q q="自分のメッセージの横に Failed to send と出る。">
<p>回線が遅いときに出ます。少し待ってください。メッセージが会話に表示されれば問題ありません。いつまでも出てこなければ、`Retry`（再試行）を押します。</p>
</Q>
<Q q="結果がおかしい。たとえば、押しても数字が変わらない。">
<p>見えたことだけを伝えてください。たとえば「3 回押したけど、数字は 0 のまま」。原因は推測しないでください。推測が外れていると、まちがった方向へ進んでしまいます。</p>
</Q>
<Q q="よくわからない質問をされた。">
<p>こう返せば大丈夫です。「私はプログラミングができません。やさしい言葉で聞いてください。または、いちばん安全なものを選んで、その理由を教えてください。」</p>
</Q>

## これで使えるようになりました

これからは、何を頼むときも同じです。まずフォルダを開き、3 つの部分でできたメッセージを送ります。たとえば：

<Copy id="ex-card" title="もう 1 つ小さなものを作る" code={`ほしいもの：「お誕生日おめでとう」と表示されて、押すと色が変わる誕生日カードのウェブページ。ここは空のフォルダです。ファイルはすべてこの中に作ってください。
できあがりの姿：ページを開くとメッセージが見える。1 回押すと色が変わる。5 回続けて押すと、毎回ちがう色になる。
終わったら見せてほしいもの：何を確かめて、何が見えたか。最後に、どのファイルをダブルクリックすれば開くか教えてください。`} />

新しい仕事のたびに、新しい空のフォルダを作り、新しい<Term k="对话" />で開いてください。

<Callout type="tip" title="今はここまでで十分です">
はじめての方に必要なのは、この 3 レッスンだけです。練習には、自分が本当にほしい小さなものを 1 つ選んで、同じ 3 つの部分で頼んでみてください。
